# Kenney Furniture Kit

Drop the GLB files from https://kenney.nl/assets/furniture-kit (Models/GLB/) here.

Required filenames (referenced by `lib/rooms/themes.ts`):

- desk.glb
- deskCorner.glb
- chairDesk.glb
- chairCushion.glb
- computerScreen.glb
- computerKeyboard.glb
- laptop.glb
- bookcaseClosed.glb
- bookcaseOpen.glb
- loungeSofa.glb
- loungeSofaCorner.glb
- pottedPlant.glb
- plantSmall.glb
- coffeeTable.glb
- lampSquareTable.glb
- rugRectangle.glb
- rugRound.glb
- kitchenFridge.glb
- kitchenStove.glb
- wallDoorway.glb
- wallWindow.glb

License: CC0 (public domain). Created by Kenney.

If models are missing, `<Furniture />` falls back to a tinted box primitive of the same footprint so the room still renders.
